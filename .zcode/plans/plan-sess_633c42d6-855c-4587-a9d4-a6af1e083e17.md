## 目标(命名已确认:admin 端 API 前缀 = `/admin-api/v1`,app 端保留 `/api/v1`)

1. **API 前缀分端**:app 端接口保留 `/api/v1/*`,admin 端接口迁移到 `/admin-api/v1/*`
2. **后端多端静态托管**:`webDir`(单目录)升级为 `webDirs`(多端),app SPA 挂根 `/`,admin SPA 挂 `/admin/`

静态路径:app 页面在 `/`,admin 页面在 `/admin/`;页面上 admin 调 `/admin-api/v1/*`,app 调 `/api/v1/*`。

## 改动清单(按实施顺序)

### 1. 后端路由与配置
- `api/internal/config/config.go`:`Server.WebDir string` → `Server.WebDirs map[string]string`(yaml `webDirs: {app: "", admin: ""}`);`applyEnv` 移除 `ADMIN_SERVER_WEB_DIR`(map 不做 env 覆盖,注释说明)
- `api/internal/router/router.go`:
  - 双路由组:`api = r.Group("/api/v1")`(app 端)+ `adminApi = r.Group("/admin-api/v1")`(admin 端),Recorder 中间件两组都挂;`routeWires` 相应改为 `appApi`/`adminApi`/`adminAuthed`
  - `mountWebDir` 重写为 `mountWebDirs`:app 目录挂根(NoRoute 回退 index.html,`/api`、`/admin-api`、`/files` 前缀返回 JSON 404),admin 目录挂 `/admin/*path`(回退 admin 自己的 index.html)
- `api/internal/router/admin.go`:改用 `w.adminApi`/`w.adminAuthed`(各路径段本身不变,只换组)
- `api/internal/router/api.go`:portal 组继续用 `w.api`(不变)
- `api/internal/handler/file_dto.go:60`:下载 URL `/api/v1/files/...` → `/admin-api/v1/files/...`
- 注释批量更新:`internal/handler/*.go` 各 godoc 里 `GET /api/v1/...` → `/admin-api/v1/...`(portal.go 除外),`service/file.go:35`、config 注释、migration 000009 注释同步

### 2. 后端测试
- `router_test.go`:58 处 URL 中除 portal demo 外全部 `/api/v1/` → `/admin-api/v1/`
- 新增测试:`mountWebDirs` 行为(admin 前缀返回 admin index、根回退 app index、API 前缀 JSON 404)+ config 解析 `webDirs` 的小测试

### 3. admin 前端
- `src/api/request.ts`:默认 baseURL `/api/v1` → `/admin-api/v1`;`env.d.ts`、`.env.production` 注释同步
- `vite.config.ts`:加 `base: '/admin/'`;proxy 键 `'/api'` 改 `'/admin-api'`(`'/files'` 保留)
- `src/router/index.ts`:`createWebHistory(import.meta.env.BASE_URL)`
- 注意:admin dev server 地址变为 `http://localhost:5173/admin/`

### 4. 部署链路

### 5. 文档
